This submission extends the same Personal Study Planner project. Modules 1–3 are retained, and Module 4 adds smart study priorities.

## Module 4 features
- Subject priority recommendations sorted by the number of pending tasks.
- Urgency cues for subjects with tasks due soon or overdue.
- Search tasks by task title or subject name.
- Filter tasks by status (all, pending, completed) and subject.
- Upcoming-deadline view for pending tasks due today or in the next seven days.
- Summary cards for pending tasks, upcoming tasks, overdue tasks, and subjects needing focus.
- Automatic refresh when tasks or subjects are added, edited, deleted, or marked complete/pending.
- Responsive Bootstrap interface and browser LocalStorage persistence.

## Technologies
HTML5, CSS3, JavaScript (ES6+), Bootstrap 5, Chart.js, LocalStorage, VS Code, Git/GitHub.

## Run locally
1. Extract the ZIP file.
2. Open the folder in VS Code.
3. Open `index.html` using Live Server, or open it directly in a browser.
4. Internet access is required for Bootstrap and Chart.js CDN files.
